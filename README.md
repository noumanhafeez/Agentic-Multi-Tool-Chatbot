# Agentic Multi-Agent Chatbot System

An intelligent **Agentic Multi-Agent Chatbot System** built using **LangGraph** for orchestrating multiple AI agents to collaborate, reason, and execute tasks dynamically. The system enables context-aware conversations through structured workflows, intelligent routing, and multi-step decision-making.

The chatbot leverages **multi-agent architecture** where specialized agents handle different responsibilities and coordinate through LangGraph state management. It supports **tool calling**, **memory management**, and **Retrieval-Augmented Generation (RAG)** to deliver accurate and relevant responses.

## Features

- Multi-agent workflow orchestration using **LangGraph**
- Dynamic agent routing and task delegation
- Multi-step reasoning and decision-making
- **RAG** for context-aware responses
- Integration with external tools and APIs
- Conversation memory and state management
- Modular and scalable architecture
- Real-time conversational interaction

## Tech Stack

- **LangGraph** – Multi-agent orchestration
- **LangChain** – LLM and tool integration
- **Python** – Backend development
- **FastAPI** – API layer
- **Vector Database** – Embedding storage and retrieval

## Architecture

User Input → Supervisor Agent → Specialized Agents → Tool Execution → Response Generation

## Goal

Build a scalable and extensible **agentic AI system** capable of handling complex user queries through coordinated agent collaboration and intelligent workflow execution.
